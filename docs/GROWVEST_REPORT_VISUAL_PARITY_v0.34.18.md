# GrowVest v0.34.18 - Locked Report Visual Parity

## Purpose
v0.34.18 is a presentation-only refinement of the locked GrowVest Signature Wealth Review. It does not change portfolio, goal, SIP, opening-baseline, reconciliation, or publishing calculations.

## Locked-reference corrections
- Restores the icon system visible in the approved reference across Wealth at a Glance, Bucket List, Performance, GrowVest View, Protection/Upcoming callouts, and the closing CTA.
- Uses Portfolio, Invested, Gain/Loss, SIP, Target, Performance, Binoculars, Compass, Gear, Shield, Calendar, Check, and GrowVest-style leaf visual roles instead of generic dots/minus marks in the native secure PDF.
- Keeps browser preview and secure downloadable PDF icon intent aligned.
- Financial tables right-align numeric columns and their secondary gain/loss details.
- Uses tabular/lining numerals in the browser renderer for stable rupee, percentage, SIP, goal, and performance alignment.
- Keeps KPI values on one consistent text grid after the icon column.
- Preserves the locked GrowVest palette: Royal Trust Blue #1F4ED8, Electric Sky-Blue #0CC0DF, Premium Black #0B0B0F, Strategic Red #E53935, Insight Yellow #F5B301, Soft Gray #F4F6F9, Medium Gray #6B7280, and White.

## No business-logic change
All v0.34.16 and v0.34.17 financial integrity rules remain intact. The release changes the report presentation layer only.
